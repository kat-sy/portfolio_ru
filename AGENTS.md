## Build and verify

- Static generation: `node src/build.mjs`; output is `dist/`.
- Tests: `node --test tests/*.test.mjs`.
- No dependency installation is needed. Preserve the buildless browser runtime.
- Keep shared personal navigation consistent and each case's original visual identity scoped independently.
- All page content and basic links must work without JavaScript. JavaScript adds comparison, image inspection and clipboard feedback.
- Keep RU/EN content complete, with matching page paths and anchor IDs.
- Use the supplied Figma and Notion sources. Never invent employers, customers, research counts, shipped-product outcomes or partnerships. Ecopart is an unbuilt app prototype; Ehope is a concept.
- The owner requests autonomous plan/build/test/refine loops and specialist agents when useful. Give agents bounded file ownership.
- Do not reinstate the cancelled company-logo request or use the accidentally pasted vacancy.
- Run applicable checks and visual browser checks when available; report the verification boundary accurately.
- Follow the Sites skill for preview deployment; preserve `.openai/hosting.json` identity and private audience. Never persist credentials.
